# Tools Research — Hansel-OS

Este directorio almacena los resultados de investigación de herramientas externas (Fase 2).

## Estructura

```
tools_research/
├── README.md                    # Este archivo
├── YYYY-MM-DD_[tema].md        # Investigación de un tema específico
└── index.json                   # Índice de todas las investigaciones
```

## Cómo usar este directorio

Cuando la Fase 2 produce resultados de búsqueda, se guardan aquí para:
1. Referencia futura (evitar buscar lo mismo dos veces)
2. Comparación (ver cómo ha evolucionado una herramienta)
3. Síntesis (combinar múltiples búsquedas de un tema)
